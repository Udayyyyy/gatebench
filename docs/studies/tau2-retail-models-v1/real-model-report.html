Method and limits

  • Complete matrix. Missing or duplicated repetitions, mismatched model/task coverage, and inconsistent grader sets are rejected by the analyzer.
  • Paired task clusters. 2,000 bootstrap draws, seed 17, retain all repetitions of each sampled domain/task pair and use the same draws for models and graders.
  • Bounded evidence. Intervals describe sensitivity to this fixed task mix. Small local models, one model family, and a limited number of seeds do not support broad capability or deployment-risk claims.
  • Separate adjudication. The hardened verifier is not independent ground truth. A disagreement alone does not establish a false positive, false negative, or intentional reward hacking.
  • Protocol provenance. Model digests, quantization, runtime/template settings, task/policy hashes, warm-up conditions, and raw outputs belong in the accompanying run manifest. Matching seeds do not guarantee identical inference on different runtimes or hardware.
  • Public benchmark scope. External domains retain their own source revision, native evaluator, task selection, and protocol departures. A fixed-user subset is not an official full-benchmark leaderboard run.
